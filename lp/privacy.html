プライバシーポリシー

最終更新日: 2025年1月1日

1. 収集する情報

本サービスでは以下の情報を収集します： ・アカウント情報（名前、メールアドレス、プロフィール写真） ・チェスのレーティング情報 ・位置情報（ユーザーが許可した場合のみ） ・対局履歴と統計 ・メッセージの内容 ・デバイス情報とアプリの利用状況

2. 情報の利用目的

収集した情報は以下の目的で利用します： ・プレイヤー同士のマッチング ・サービスの改善と最適化 ・カスタマーサポートの提供 ・不正行為の検出と防止 ・利用統計の分析

3. 情報の共有

ユーザーの個人情報を第三者に販売することはありません。以下の場合に限り情報を共有する場合があります： ・ユーザーの同意がある場合 ・法的要求に応じる必要がある場合 ・サービスの運営に必要な業務委託先との共有

4. 位置情報について

位置情報はプレイヤーのマッチングにのみ使用され、アプリの設定でいつでもオフにできます。アプリ起動中以外は位置情報を取得しません。正確な位置情報は他のプレイヤーに公開されず、おおよその距離のみが表示されます。

5. データの保護

業界標準のセキュリティ対策を実施し、ユーザーデータの保護に努めています。通信は暗号化され、データは安全なサーバーに保管されます。

6. ユーザーの権利

ユーザーは以下の権利を有します： ・自己のデータへのアクセス権 ・データの修正・削除の要求 ・データ処理への同意の撤回 ・データの出力要求 上記の権利の行使は、設定画面またはサポートへのお問い合わせにより可能です。

7. 翻訳機能について

翻訳ボタンを押した場合、選択したテキスト（投稿・コメント・メッセージ等）が翻訳サービスの提供のため、第三者（Google Cloud Translation API、MyMemory API 等）に送信されます。送信されたテキストは翻訳目的でのみ使用され、当該サービスによる学習・他目的利用は行われません。翻訳はユーザーがボタンを押した場合にのみ実行されます。

8. お問い合わせ

プライバシーに関するお問い合わせは、chessenger.co.ltd@gmail.com までご連絡ください。通報もメールで承っております。
